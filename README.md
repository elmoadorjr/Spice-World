# Spice World

**The Nusantara, 1500 AD** — an interactive map and voyage game of the spice trade era in maritime Southeast Asia.

## What's inside

The whole game ships as a single `index.html`:

- **Spice World Map** — an interactive Leaflet chart of the Nusantara with layers for kingdoms and spheres of influence, trade routes and goods flows, monsoon winds, volcanoes, settlements, and pilgrimage sites.
- **Worldbuilding tabs** — character sheets, locations, connections, conflicts, mythos, ledger, almanac, vessels, goods, and economy.
- **Nakhoda Mode** — an embedded 3D sailing sim (Three.js): captain a jong through the Eastern Seas, trading between ports, riding the monsoon, and dodging pirates.

## Play

Play online: https://elmoadorjr.github.io/Spice-World/

Or locally — just open `index.html` in a browser (an internet connection is needed for the map/font/3D libraries loaded from CDNs).
